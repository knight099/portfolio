# 📈 TheLastTrade.com

**TheLastTrade.com** delivers trading education and reference tools for beginner-to-intermediate traders, with a direct WhatsApp support channel built in.

## Key Features

- **Trading Education:**
  Structured course content covering core trading concepts and strategy.

- **User Support:**
  WhatsApp-integrated support channel for real-time user questions.

- **Deployment:**
  CI-deployed on Vercel with a custom domain.

## Tech Stack

React (frontend), Node.js/Express (backend), MongoDB (data layer).
