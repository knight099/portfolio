# 🤝 GetColabb

**GetColabb** is a full-stack brand-creator collaboration platform, currently MVP ready and in private beta at [getcolabb.com](https://getcolabb.com).

---

## 🔍 Overview

### Key Features:
- **Smart Matching Engine:**
  Engineered a smart creator-brand matching engine to connect the right partners efficiently.

- **Escrow Payment System:**
  Built a secure escrow payment system for campaign transactions.

- **Campaign Management:**
  Full campaign lifecycle management for brands and creators.

- **Verified Analytics Dashboards:**
  OAuth-connected analytics dashboards using Meta APIs (Instagram/Facebook OAuth).

- **Real-Time Messaging:**
  In-platform real-time messaging between brands and creators.

### Tech Stack:
Flutter (mobile), Go (backend), React.js/Next.js (web), PostgreSQL, AWS (S3, App Runner, ECR), Meta APIs.
