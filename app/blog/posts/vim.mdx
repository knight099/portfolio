# Backend Developer at Tata Consultancy Services

Nearly four years on backend and platform work at **TCS** in Bangalore, moving a legacy monolith to microservices and hardening the systems around it.

## Scope & Impact

- **Microservices Migration:**
  Led the migration of legacy monolithic systems to microservices using Python, Flask, and MySQL, coordinating the cutover across **5+ service teams** with no downtime.

- **CI/CD & Delivery:**
  Containerized services with Docker and rebuilt the Jenkins pipeline, cutting deployment time from hours to minutes — a **44% reduction**.

- **Event-Driven Architecture:**
  Introduced Apache Kafka and Apache Camel for inter-service communication, replacing brittle synchronous calls with reliable event streams.

- **Search & Query Performance:**
  Integrated Elasticsearch and layered GraphQL with CQRS on top of the API surface, achieving **50% faster** query response times.

- **Quality & Reliability:**
  Held **90%+ unit test coverage** across releases and drove low-level design reviews focused on fault tolerance, lifting team development velocity by **35%**.

- **Mentorship:**
  Mentored junior engineers through sprint planning, code review, and design discussions as part of the team's agile process.
