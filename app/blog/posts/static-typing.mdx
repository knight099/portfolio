# 🌱 Plant AI Assistant

[Live](https://plant-identifier-blush.vercel.app/) · [Source](https://github.com/knight099/Plant-Identifier)

**Plant AI Assistant** analyzes plant photos and conditions via the Gemini API to give personalized care recommendations.

## Key Features

- **AI-Powered Diagnosis:**
  Uses the Gemini AI API to analyze plant conditions and generate tailored care tips.

- **Interactive UI:**
  Built with Next.js and Tailwind CSS for a responsive, low-latency interface.

- **Deployment:**
  Deployed on Vercel with edge caching for fast global load times.
