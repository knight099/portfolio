# 🎥 NightWatch

**NightWatch** is an AI security platform that plugs into existing CCTV cameras and automatically detects anomalous events—intrusions, loitering, restricted-zone violations—without requiring human monitoring.

---

## 🔍 Overview

### Key Features:
- **Snapshot-Based CV Analysis:**
  Instead of streaming live video, the system captures periodic snapshots and runs Computer Vision (CV) analysis with **OpenCV**, sending instant alerts with timestamped evidence only when a real threat is detected.

- **Real-Time Alert Dashboard:**
  Businesses get a real-time alert dashboard and event history, turning passive camera infrastructure into an active, intelligent security layer.

- **Zero Hardware Replacement:**
  Works with existing CCTV setups—no new hardware required.
